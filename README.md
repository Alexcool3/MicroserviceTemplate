# AuthService

---

## 🛠️ Prerequisites

Following must be installed to run this service

- [.NET 9 SDK](https://dotnet.microsoft.com/) (or newer)
- Access to GitHub Packages such has the `SharedKernel`NuGet package.

---

## API Documentation

Once the service is running, you can explore and test the endpoints via Scalar:
URL: https://localhost:5001/scalar/v1 (or the port assigned by Kestrel).
